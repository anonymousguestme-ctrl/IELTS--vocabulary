# IELTS Vocabulary Bench｜本地的雅思单词本

一个面向中文学习者的本地雅思词汇本：把不会的单词、短语和句子放进来，标记掌握状态，再打印成通勤复习清单。

## 在线使用

打开仓库中的 [`index.html`](./index.html) 即可使用。不需要安装依赖，不需要账号，也不需要后端服务。此方式支持内置词库和公开词典查询；如果要使用 DeepSeek 补全未收录内容，请按下方方式启动本地代理。

```bash
open index.html
```

## 功能总览

- 雅思单词、短语、句子分开记录。
- 本地离线词库自动匹配词性和中文释义。
- 约 1.2 万个内置词条，覆盖雅思听力、学术和场景词汇。
- 额外接入 `hefengxian/my-ielts` 的 3697 个带词性、释义和例句的词条。
- 词性、释义可修改；短语和例句可以留空。
- 一键隐藏全部词性和释义，适合先回忆再核对。
- 勾选“已掌握”，按“全部 / 不会 / 会了”筛选。
- 只打印待背内容，适合地铁上使用。
- 学习记录保存在当前浏览器本地。
- 点击词汇卡片可回填到左侧表单进行编辑，保存后直接更新原卡片。
- 关联词汇可按行填写；卡片会显示关联词汇组，点击关联词即可筛选同组内容。

## 界面说明

### 1. 主界面：统计、录入和词汇列表

顶部是总词汇、待背、已掌握和掌握进度；中部是筛选、搜索和打印；下方左侧录入，右侧展示词汇卡片。

### 2. 添加单词

在录入区输入英文单词，离开输入框后会优先从本地词库匹配。匹配结果会填入词性和中文释义，可以直接修改。

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 单词 | 需要记忆的英文词 | 是 |
| 词性 | 例如 `n. 名词`、`v. 动词` | 否，可修改 |
| 释义 | 中文解释，可填多个义项 | 否，可修改 |
| 常用短语 | 每行一个搭配 | 否 |
| 例句 | 帮助记忆的完整句子 | 否 |

### 3. 添加短语或句子

录入区有三个模式，逻辑彼此独立：

- **单词**：填写单词，自动匹配词性、释义和词库中已有的常用短语；例句是可选的。DeepSeek 补全时会为每个短语附上中文释义，格式为“英文短语｜中文释义”。
- **短语 / 固定搭配**：把整个搭配作为条目，例如 `carry out research`。短语没有独立词性，因此不显示词性选择；可以自动匹配或手动填写中文释义，也可以补充一个例句。
- **句子**：把听力原句、写作模板或自己的例句作为条目。句子不属于词性词义条目，因此不查询、不显示词性、释义和常用短语。

三种模式都可以按 Enter 提交。空的短语或例句不会在卡片中显示。

### 4. 词汇卡片

每张卡片把英文词、词性和中文释义排在同一信息带中，下面再显示已有的短语和例句。卡片左侧复选框用于标记掌握状态。

阅读顺序：英文词汇 → 词性 → 中文释义 → 短语（有内容才显示）→ 例句（有内容才显示）。

### 5. 一键隐藏释义

词汇列表标题右侧的“隐藏释义”按钮会一次隐藏所有卡片的词性和中文释义。按钮变成“显示释义”后，再次点击即可恢复，适合先看英文回忆中文意思，再核对答案。

### 6. 关联词汇

在录入区的“关联词汇”中每行填写一个词，或用逗号分隔。保存单词时，系统会为尚未存在的关联词自动创建独立词汇卡，并优先从离线词库填入词性和释义；卡片中的关联词按钮用于快速筛选同组条目。

![关联词汇卡片示例](./docs/related-vocabulary.jpg)

上图展示了关联词汇在词汇列表中的卡片效果：每个关联词都作为独立条目出现，可以分别标记掌握状态。

### 近义词程度与词性

对于容易混淆的词，卡片会显示“近义词程度与用法”。例如 `disastrous` 表示结果很糟，`catastrophic` 通常表示更大范围、更严重的破坏；`calamity` 是名词，指灾祸本身，不能直接当形容词使用。这个模块比较的是语气和用法，不把不同词性强行当成完全同义词。

### 7. 筛选和打印

点击“不会”只显示还没有掌握的词，然后点击“打印当前清单”。打印样式会自动隐藏录入区、搜索区、操作按钮和已掌握词条。

1. 点击“不会”。
2. 用搜索框缩小到某一主题或章节（可选）。
3. 点击“打印当前清单”。
4. 选择打印机，或选择“存储为 PDF”。

## 查询逻辑

查询顺序：浏览器本地缓存 → 内置 Excel 词库 → GitHub IELTS Word List 词库 → 公开英文词典接口（仅在本地没有命中时尝试）。本地词库命中时不需要联网；联网查询最多等待 4 秒，超时后仍然可以手动填写并保存。

```text
输入单词或短语
      │
      ▼
浏览器本地缓存 ──命中──> 填入词性和释义
      │ 未命中
      ▼
内置雅思词库（Excel / GitHub 词库）
      │
      ├─命中──> 填入词性和释义
      │
      └─未命中
            ▼
      公开英文词典接口
            │
      ├─成功──> 填入词性和释义
      │
      └─超时或失败──> 已保存 Key？
                              │是
                              ▼
                      本地 server.py 代理
                              │
                              ▼
                       DeepSeek 返回 JSON
                              │
                              ▼
                    填入词性、释义、短语、例句
                              │否
                              ▼
                 提示保存 Key，或手动填写
```

当公开词典查询超时或未找到时，如果浏览器中已保存 Key，DeepSeek 会自动查询并填入释义、词性、解释、短语和例句；页面按钮仍可用于手动重试。自动调用只发生在公开词典失败后，避免重复消耗 API。

### DeepSeek 补全未收录内容

DeepSeek 通过本地 `server.py` 代理调用。默认隐藏 API Key 设置，需要点击“DeepSeek 设置”展开；粘贴 Key 后点击“保存 Key”。Key 只保存在当前浏览器的 `localStorage`，不会提交到 GitHub。需要 Python 3 启动代理：

```bash
cd "/Users/adele/Desktop/IELTS- vocabulary"
python3 server.py
```

然后打开 `http://127.0.0.1:8765/`，保存 Key 后，在单词或短语模式点击“用 DeepSeek 查询未收录词”。也可以使用环境变量 `DEEPSEEK_API_KEY`，环境变量优先于页面输入。句子模式不会调用 DeepSeek。保存 Key 会提升便利性，但不适合在共享电脑上使用，离开设备前可点击“清除”。

## 数据与隐私

- 新增词条、掌握状态和查询缓存保存在当前浏览器的 `localStorage` 中。
- 数据不会自动上传到本项目。
- 清除浏览器站点数据、使用隐私窗口或更换浏览器后，本地记录可能不可见。

## 内置词库来源

1. **雅思王听力语料库（剑19版）**：本地的《语料库练习模板(剑19)-2025.7.6.xlsx》整理文件。
2. [`fanhongtao/IELTS`](https://github.com/fanhongtao/IELTS) 中的 `IELTS Word List.txt`。
3. [`hefengxian/my-ielts`](https://github.com/hefengxian/my-ielts) 的词汇模块数据。

词库内容仅用于个人学习整理，词义和完整性以原始资料为准。

## 技术说明

- 纯 HTML、CSS 和原生 JavaScript。
- 不依赖构建工具和前端框架。
- 通过 `localStorage` 持久化学习记录。
- 可直接打开 HTML，也可以部署到任意静态文件托管服务。

## 当前限制

- 部分源词条只有单词和释义，没有短语或例句。
- 当前版本是单机本地版，不提供跨设备同步。
- DeepSeek 功能需要自行提供 API Key，并依赖网络；未启动 `server.py` 时按钮会提示无法连接。
